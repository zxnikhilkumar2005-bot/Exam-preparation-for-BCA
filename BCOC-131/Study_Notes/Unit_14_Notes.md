## 14.1 INDEPENDENT BRANCH

### **Definition:**
Branch that **maintains its own complete set of books** under double entry system. Prepares its own Trial Balance, Trading & P&L Account, and Balance Sheet.

### **Key Features:**
- Own books, own bank account
- Purchases locally + receives goods from HO
- Prepares independent financial statements
- HO incorporates branch results via **incorporation entries**

---

## 14.2 INCORPORATION OF BRANCH TRIAL BALANCE IN HO BOOKS

### **Step 1: Branch prepares Trial Balance**
- Sent to HO at period end
- HO verifies and incorporates

### **Step 2: HO passes Incorporation Entries**

| Transaction | Journal Entry in HO Books |
|-------------|---------------------------|
| **1. Branch Assets** | Branch Asset A/c Dr.<br>To Branch A/c |
| **2. Branch Liabilities** | Branch A/c Dr.<br>To Branch Liability A/c |
| **3. Goods Received from HO** | Branch A/c Dr. (at IP)<br>To Goods Sent to Branch A/c (at IP) |
| **4. Loading on Goods Received** | Goods Sent to Branch A/c Dr. (Loading)<br>To Branch Adjustment A/c (Loading) |
| **5. Cash in Transit** | Cash in Transit A/c Dr.<br>To Branch A/c |
| **6. Branch Expenses Paid by HO** | Branch A/c Dr.<br>To Cash/Bank A/c |
| **7. HO Expenses Allocated to Branch** | Branch A/c Dr.<br>To Expense A/c |
| **8. Depreciation on Branch Assets (HO books)** | Branch P&L A/c Dr.<br>To Branch Asset A/c |
| **9. Inter-branch Transactions** | Recipient Branch A/c Dr.<br>To Supplying Branch A/c |
| **10. Profit Transfer** | Branch A/c Dr.<br>To P&L A/c (HO) |

## 14.3 RECONCILIATION OF BRANCH AND HO ACCOUNTS

### **Causes of Difference:**
1. **Cash in Transit** - Cash sent by branch not received by HO
2. **Goods in Transit** - Goods dispatched by HO not received by branch
3. **Different Valuation** - HO at IP, Branch at Cost (or vice versa)
4. **Timing Differences** - Entries recorded in different periods
5. **Errors** - Mistakes in either set of books

### **Reconciliation Statement:**

```
RECONCILIATION OF BRANCH AND HO ACCOUNTS
As on 31st March, 2024

Balance as per Branch Books                          ₹
Add: Cash in Transit                                 xxx
Add: Goods in Transit (at IP)                        xxx
Less: Loading on Goods in Transit                    (xxx)
Less: Expenses paid by HO not recorded by Branch     (xxx)
Less: Depreciation recorded by HO not by Branch      (xxx)
Add: Income received by HO not recorded by Branch    xxx
                                                         ----
Balance as per HO Books (Branch Account)             xxx
```

## 14.4 BRANCH FIXED ASSETS - ACCOUNTS KEPT AT HO LEVEL 🔴 HIGH PRIORITY (Dec 2025 - 10 marks)

### **Scenario:**
Branch fixed assets purchased by branch but **accounted in HO books** (not in branch books).

### **Accounting Treatment:**

**In HO Books:**

| Transaction | Journal Entry |
|-------------|---------------|
| **1. Asset Purchased by Branch** | Branch Fixed Asset A/c Dr.<br>To Branch A/c |
| **2. Expenses on Purchase (by Branch)** | Branch Fixed Asset A/c Dr.<br>To Branch A/c |
| **3. Depreciation (Year-end)** | Branch P&L A/c Dr.<br>To Branch Fixed Asset A/c |
| **4. Asset Sold by Branch** | Bank A/c Dr. (Sale Proceeds)<br>Branch Fixed Asset A/c Dr. (WDV)<br>To Branch A/c (Book Value)<br>To Branch P&L A/c (Profit/Loss) |

**In Branch Books:**
- **NO ASSET ACCOUNT** maintained
- **NO DEPRECIATION** recorded
- Only: Remittance to HO for asset purchase, Receipt of sale proceeds

### **Example:**
Branch purchases machinery ₹50,000, pays ₹2,000 installation. HO depreciates @10% WDV.

**HO Books:**
```
Machinery A/c (Branch)    Dr.    52,000
    To Branch A/c                    52,000

Branch P&L A/c            Dr.    5,200
    To Machinery A/c (Branch)        5,200
```

**Branch Books:**
```
Branch A/c                Dr.    52,000
    To Bank A/c                        52,000
```

## 14.5 INTER-BRANCH TRANSACTIONS

### **When Goods Transferred Between Branches:**

| In Supplying Branch Books | In Receiving Branch Books |
|---------------------------|---------------------------|
| Receiving Branch A/c Dr. (IP)<br>To Branch Stock A/c (IP) | Branch Stock A/c Dr. (IP)<br>To Supplying Branch A/c (IP) |
| Loading: Branch Adj A/c Dr.<br>To Supplying Branch A/c | Loading: Supplying Branch A/c Dr.<br>To Branch Adj A/c |

**In HO Books (if centralized):**
```
Receiving Branch A/c    Dr.
    To Supplying Branch A/c
```

## 14.6 FOREIGN BRANCH (OVERVIEW)

### **Definition:**
Branch located in a **foreign country** with different currency.

### **Key Issues:**
1. **Currency Translation** - Foreign currency to reporting currency
2. **Exchange Rate Fluctuations** - Gains/losses on translation
3. **Methods of Translation:**
   - **Current Rate Method** - All items at closing rate
   - **Temporal Method** - Monetary at closing, non-monetary at historical
4. **AS 11 / Ind AS 21** - Governs foreign branch accounting

### **Accounting Treatment (Simplified):**
- Branch maintains books in local currency
- HO translates at appropriate rates
- Exchange differences → P&L or Reserve (per standard)

> **Note:** Detailed foreign branch accounting is beyond BCOC-131 scope. Basic awareness sufficient.

## 14.7 WHOLESALE BRANCH METHOD

### **Concept:**
HO supplies goods to **Regional Branch (Wholesale)** at wholesale price, which then supplies to **Retail Branches** at retail price.

### **Accounting:**
- Wholesale Branch = Treated as dependent branch of HO
- Retail Branches = Dependent branches of Wholesale Branch
- Separate accounts for each level

---

## 14.8 FINAL ACCOUNTS SYSTEM FOR BRANCHES

### **When Branch Prepares Own Final Accounts:**
1. Branch prepares: Trading A/c, P&L A/c, Balance Sheet
2. Sends to HO
3. HO incorporates via journal entries (same as Independent Branch)

### **Advantages:**
- Branch autonomy
- Local management accountability
- Detailed local reporting

## 14.10 KEY POINTS FOR REVISION

- ✅ **Independent Branch** = Own books, own TB, HO incorporates via entries
- ✅ **Incorporation Entries** = Assets Dr/To Branch, Branch Dr/To Liabilities, etc.
- ✅ **Reconciliation** = Cash in Transit, Goods in Transit, Timing differences
- ✅ **Branch Fixed Assets at HO** = Asset in HO books, NO asset in Branch books
- ✅ **Depreciation on Branch Assets** = Charged by HO to Branch P&L
- ✅ **Inter-branch** = Transfer at IP with loading adjustments
- ✅ **Foreign Branch** = Currency translation per AS 11/Ind AS 21
