## 📌 QUICK REFERENCE FORMULAS

| Topic | Formula |
|-------|---------|
| **Loading %** | If Cost + x% = IP → Loading = x/(100+x) × 100 |
| **Depreciation (SLM)** | (Cost - Scrap) / Useful Life |
| **Depreciation (WDV)** | Rate × WDV at beginning |
| **WDV Rate** | 1 - n√(Scrap/Cost) |
| **Interest (HP)** | Opening Balance × Rate × Period |
| **Commission on Profit** | Before: Profit × Rate / After: Profit × Rate/(100+Rate) |
| **Closing Stock (Consignment)** | (Cost of Goods Sent × Unsold Qty / Total Qty) + Proportionate Non-recurring Expenses |
| **Abnormal Loss Value** | Same as good units (after normal loss adjustment) |
| **Cost of Goods Sold** | Opening Stock + Purchases - Purchase Returns + Direct Expenses - Closing Stock |
| **Gross Profit** | Sales - Sales Returns - Cost of Goods Sold |
