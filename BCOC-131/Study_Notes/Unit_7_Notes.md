## 7.1 TRIAL BALANCE

### **Definition:**
A statement showing **debit and credit balances** of all ledger accounts on a particular date to **verify arithmetical accuracy** of books of account.

### **Objectives:**
1. Check arithmetical accuracy (Total Debits = Total Credits)
2. Help locate errors
3. Basis for preparing Final Accounts
4. Summary of all ledger balances

### **Methods of Preparation:**
1. **Balance Method** - Only net balances shown (most common)
2. **Total Method** - Totals of debit/credit sides of each account
3. **Compound Method** - Both balances and totals

### **Format (Balance Method):**

```
TRIAL BALANCE AS ON 31ST MARCH, 2024

| Account Name              | L.F. | Debit Balance (₹) | Credit Balance (₹) |
|---------------------------|------|-------------------|--------------------|
| Capital A/c               |      |                   | 1,00,000           |
| Drawings A/c              |      | 10,000            |                    |
| Machinery A/c             |      | 80,000            |                    |
| Furniture A/c             |      | 20,000            |                    |
| Stock A/c                 |      | 30,000            |                    |
| Debtors A/c               |      | 25,000            |                    |
| Creditors A/c             |      |                   | 15,000             |
| Cash A/c                  |      | 5,000             |                    |
| Bank A/c                  |      | 15,000            |                    |
| Purchases A/c             |      | 60,000            |                    |
| Sales A/c                 |      |                   | 90,000             |
| Purchase Returns A/c      |      |                   | 2,000              |
| Sales Returns A/c         |      | 1,000             |                    |
| Wages A/c                 |      | 12,000            |                    |
| Salaries A/c              |      | 8,000             |                    |
| Rent A/c                  |      | 6,000             |                    |
| Commission Received A/c   |      |                   | 5,000              |
| Discount Allowed A/c      |      | 1,000             |                    |
| Discount Received A/c     |      |                   | 500                |
| **TOTAL**                 |      | **2,73,000**      | **2,73,000**       |
```

### **Limitations of Trial Balance:**
Trial Balance **agreeing does NOT prove absolute accuracy**. Errors NOT detected:
1. **Error of Omission** - Transaction completely omitted
2. **Error of Commission** - Wrong account but same class (e.g., Ram instead of Shyam)
3. **Error of Principle** - Wrong classification (e.g., Machinery debited to Purchases)
4. **Compensating Errors** - Two errors cancel each other (e.g., Sales overcast ₹100, Purchases overcast ₹100)
5. **Wrong Amount in Original Book** - Both debit & credit wrong by same amount

## 7.2 ERRORS AND THEIR CLASSIFICATION

### **Types of Errors:**

```mermaid
graph TD
    A[Errors] --> B[Errors NOT Affecting TB<br/>(Two-sided Errors)]
    A --> C[Errors AFFECTING TB<br/>(One-sided Errors)]
    
    B --> B1[Error of Omission<br/>Complete omission]
    B --> B2[Error of Commission<br/>Wrong account, same class]
    B --> B3[Error of Principle<br/>Wrong classification]
    B --> B4[Compensating Errors<br/>Two errors cancel out]
    
    C --> C1[Partial Omission<br/>One side not posted]
    C --> C2[Wrong Amount Posted<br/>One side wrong amount]
    C --> C3[Wrong Side Posting<br/>Debit posted as credit or vice versa]
    C --> C4[Subsidiary Book Errors<br/>Over/Under casting]
    C --> C5[Wrong Carry Forward<br/>Wrong total carried forward]
```

### **Detailed Classification:**

| Error Type | Description | Effect on TB | Rectification |
|------------|-------------|--------------|---------------|
| **1. Error of Omission** | Transaction completely not recorded | No effect | Record the missed entry |
| **2. Error of Commission** | Wrong account debited/credited (same class) | No effect | Reverse wrong, record correct |
| **3. Error of Principle** | Violates accounting principle (capital vs revenue) | No effect | Correct classification entry |
| **4. Compensating Errors** | Two/more errors cancel each other's effect | No effect | Correct both errors separately |
| **5. Partial Omission** | One aspect not posted (e.g., only debit posted) | TB disagrees | Complete the entry via Suspense |
| **6. Wrong Amount (One side)** | Different amounts on debit/credit sides | TB disagrees | Difference to Suspense |
| **7. Wrong Side Posting** | Debit posted as credit or vice versa | TB disagrees | Double amount to Suspense |
| **8. Over/Under Casting** | Subsidiary book total wrong | TB disagrees | Difference to Suspense |
| **9. Wrong Carry Forward** | Balance carried forward incorrectly | TB disagrees | Difference to Suspense |

## 7.3 RECTIFICATION OF ERRORS

### **Steps for Rectification:**
1. **Identify** the error and accounts affected
2. **Determine** if error affects TB (one-sided) or not (two-sided)
3. **Pass Rectifying Journal Entry**
4. **If TB affected** → Use **Suspense Account**
5. **If TB not affected** → Direct Journal Entry (no Suspense)

### **Rectification Entries - Common Patterns:**

| Error | Wrong Entry | Rectifying Entry |
|-------|-------------|------------------|
| **Sale to Ram ₹5,000 omitted** | -- | Ram A/c Dr. 5,000 / To Sales A/c 5,000 |
| **Sale to Shyam ₹5,000 posted to Ram** | Ram Dr. / To Sales | Shyam Dr. / To Ram |
| **Machinery ₹10,000 debited to Purchases** | Purchases Dr. / To Cash | Machinery Dr. / To Purchases |
| **Sales Book overcast ₹100, Purchases Book overcast ₹100** | Both overcast | Sales Dr. 100 / To Suspense 100; Purchases Dr. 100 / To Suspense 100 |
| **Sale ₹500 posted as ₹50** | Debtor Dr. 50 / To Sales 50 | Debtor Dr. 450 / To Sales 450 |
| **Cash received ₹1,000 credited to Debtor** | Debtor Dr. / To Cash (wrong) | Cash Dr. 2,000 / To Debtor 2,000 (double) |
| **Sales Book undercast ₹100** | Sales short by 100 | Suspense Dr. 100 / To Sales 100 |
| **Purchase Book overcast ₹200** | Purchases excess 200 | Purchases Dr. 200 / To Suspense 200 |

### **Key Rules for Rectification:**
- **Two-sided errors** → Simple Journal Entry (NO Suspense)
- **One-sided errors** → Suspense Account MUST be used
- **Subsidiary book casting errors** → Difference to Suspense
- **Wrong side posting** → Double amount to Suspense

## 7.4 SUSPENSE ACCOUNT 🔴 HIGHEST PRIORITY

### **Definition:**
A **temporary account** opened when Trial Balance **does not agree**. Difference is placed in Suspense Account to make TB agree temporarily. Later, errors are rectified and Suspense Account is closed.

### **When to Open:**
- Trial Balance totals don't match
- Difference placed on **smaller side** to balance TB
- If Credit > Debit → Suspense on **Debit side**
- If Debit > Credit → Suspense on **Credit side**

### **Format of Suspense Account:**

```
DR.                              SUSPENSE ACCOUNT                              CR.
Date       Particulars           J.F.    Amount (₹)      Date       Particulars           J.F.    Amount (₹)
                                                     2024
                                                     Mar 31   To Difference in TB            1,455
                                                     Mar 31   By Ram A/c (Rectification)      500
                                                     Mar 31   By Sales A/c (Undercast)        100
                                                     Mar 31   By Purchases A/c (Overcast)     200
                                                     Mar 31   By Balance c/d                  655
                                                     ----                               ----
                                                     Total                              1,455
                                                     ----                               ----
                                                     2024
Apr 1      To Balance b/d              655
```

### **Journal Entries with Suspense:**

| Error | Rectifying Entry |
|-------|------------------|
| Sales Book undercast ₹100 | Suspense A/c Dr. 100 / To Sales A/c 100 |
| Purchase Book overcast ₹200 | Purchases A/c Dr. 200 / To Suspense A/c 200 |
| Cash received ₹1,000 wrongly credited to Debtor | Cash A/c Dr. 2,000 / To Suspense A/c 2,000 |
| Machinery ₹5,000 debited to Purchases | Machinery A/c Dr. 5,000 / To Suspense A/c 5,000 |

> **Note:** After all errors rectified, Suspense Account should **close to zero**. If balance remains → Undetected errors exist.

## 7.5 EFFECT OF ERRORS ON PROFIT

### **Errors Affecting Profit (Nominal Accounts involved):**

| Error | Effect on Profit | Rectification Effect |
|-------|------------------|---------------------|
| Expense understated | Profit **overstated** | Profit decreases |
| Expense overstated | Profit **understated** | Profit increases |
| Income understated | Profit **understated** | Profit increases |
| Income overstated | Profit **overstated** | Profit decreases |
| Revenue expense treated as capital | Profit **overstated** | Profit decreases |
| Capital expense treated as revenue | Profit **understated** | Profit increases |

### **Errors NOT Affecting Profit (Only Real/Personal Accounts):**
- Debtor/Creditor posting errors
- Asset purchase/sale errors (unless depreciation affected)
- Cash/Bank errors

## 7.6 STANDARD PYQ PROBLEM FORMAT (20 MARKS)

### **Typical Question:**
> "The Trial Balance of X did not tally. The credit side exceeded by ₹1,455. This amount was entered in the debit column against Suspense Account. Later, the following errors were discovered:
> 1. Goods sold to Ram ₹5,000 entered in Sales Book but not posted.
> 2. Purchase Book overcast by ₹200.
> 3. Cash received from Shyam ₹1,000 credited to Ram.
> 4. Machinery purchased ₹10,000 debited to Purchases Account.
> 5. Sales Returns Book undercast by ₹100.
> Pass rectifying entries and prepare Suspense Account."

### **Solution Approach:**

**Step 1: Analyze each error**

| Error | Type | TB Effect | Rectifying Entry |
|-------|------|-----------|------------------|
| 1. Sale to Ram not posted | Partial Omission | Disagrees | Ram Dr. 5,000 / To Suspense 5,000 |
| 2. Purchase Book overcast ₹200 | Casting Error | Disagrees | Purchases Dr. 200 / To Suspense 200 |
| 3. Cash from Shyam credited to Ram | Wrong Side + Wrong Account | Disagrees | Ram Dr. 2,000 / To Suspense 2,000 |
| 4. Machinery debited to Purchases | Error of Principle | No Effect | Machinery Dr. 10,000 / To Purchases 10,000 |
| 5. Sales Returns undercast ₹100 | Casting Error | Disagrees | Suspense Dr. 100 / To Sales Returns 100 |

**Step 2: Prepare Suspense Account**

```
DR.                              SUSPENSE ACCOUNT                              CR.
Date       Particulars           Amount          Date       Particulars           Amount
2024                                                2024
Mar 31   To Difference in TB       1,455         Mar 31   By Ram A/c (Error 1)        5,000
Mar 31   To Sales Returns (Error 5)  100         Mar 31   By Purchases (Error 2)      200
                                                     Mar 31   By Ram A/c (Error 3)      2,000
                                                     Mar 31   By Balance c/d            5,355
                                                     ----                              ----
                                                     Total                           1,555
                                                     ----                              ----
```

**Step 3: Balance = ₹5,355 (Credit)** - Indicates more errors undetected or opening difference was wrong.

## 7.8 KEY POINTS FOR REVISION

- ✅ **Trial Balance** = Arithmetical accuracy check (NOT absolute accuracy)
- ✅ **4 Errors NOT affecting TB:** Omission, Commission, Principle, Compensating
- ✅ **5 Errors AFFECTING TB:** Partial Omission, Wrong Amount, Wrong Side, Over/Under Casting, Wrong Carry Forward
- ✅ **Two-sided errors** → Direct Journal Entry (No Suspense)
- ✅ **One-sided errors** → Suspense Account MUST be used
- ✅ **Suspense Account** = Temporary, opened on smaller side of TB difference
- ✅ **Wrong side posting** → Double amount to Suspense
- ✅ **Subsidiary book casting** → Difference to Suspense
- ✅ **Error of Principle** = Capital vs Revenue misclassification (No TB effect)
- ✅ **Compensating Errors** = Two errors cancel out (No TB effect)
- ✅ **After all rectification** → Suspense Account should close to ZERO

## 7.9 MEMORY AIDS

### **Errors NOT Affecting TB: "OCPC"**
- **O**mission (Complete)
- **C**ommission (Wrong account, same class)
- **P**rinciple (Wrong classification)
- **C**ompensating (Mutual cancellation)

### **Errors AFFECTING TB: "POWWCC"**
- **P**artial Omission
- **O**ver/Under Casting
- **W**rong Amount (one side)
- **W**rong Side Posting
- **C**arry Forward Wrong
- **C** (in Suspense entries)

### **Rectification Rule: "2S = No Suspense, 1S = Suspense"**
- **Two-Sided** error → No Suspense
- **One-Sided** error → Suspense Account
