## 📝 IMPORTANT SHORT ANSWERS (5-Mark Style)

### 1. Frequency Distribution & Histogram
**Steps**: (1) Find range = Max - Min, (2) Choose class width (e.g., 5 or 10), (3) Create class intervals, (4) Tally frequencies, (5) Draw histogram (bars touching, area ∝ frequency)

### 2. Mean & SD from Grouped Data
**Mean**: x̄ = Σfx / Σf  
**SD**: σ = √[Σf(x-x̄)²/Σf] = √[Σfx²/Σf - x̄²]  
**CV** = (σ/x̄) × 100%

### 3. Systematic Random Sampling
**Procedure**: (1) N = population size, n = sample size, (2) k = N/n (sampling interval), (3) Random start r ∈ [1,k], (4) Select r, r+k, r+2k, ...
**Linear**: Stop at end | **Circular**: Wrap around modulo N

### 4. Moving Average (Length 3)
MAₜ = (Yₜ₋₁ + Yₜ + Yₜ₊₁)/3 for t=2 to n-1  
Plot: Original data + MA on same graph, MA smooths fluctuations

### 5. Additive Law of Probability
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)  
If mutually exclusive: P(A ∪ B) = P(A) + P(B)

### 6. Bayes' Theorem
P(A|B) = P(B|A)P(A) / P(B) where P(B) = Σ P(B|Aᵢ)P(Aᵢ)

### 7. Binomial Distribution
PMF: P(X=x) = C(n,x) pˣ (1-p)ⁿ⁻ˣ  
Mean = np, Variance = np(1-p)

### 8. Confidence Interval for Mean (σ known)
CI = x̄ ± Z_{α/2} (σ/√n)  
**σ unknown, n≥30**: x̄ ± Z_{α/2} (s/√n)  
**σ unknown, n<30**: x̄ ± t_{α/2, n-1} (s/√n)

### 9. Paired t-test
H₀: μ_d = 0 vs H₁: μ_d ≠ 0 (or >/<)  
t = d̄ / (s_d/√n) with df = n-1  
where dᵢ = xᵢ - yᵢ (differences)

### 10. One-way ANOVA Table

| Source | SS | df | MS | F |
|--------|-----|-----|-----|-----|
| Between | SSB = Σnᵢ(x̄ᵢ - x̄)² | k-1 | MSB = SSB/(k-1) | MSB/MSW |
| Within | SSW = ΣΣ(xᵢⱼ - x̄ᵢ)² | N-k | MSW = SSW/(N-k) | |
| Total | SST = SSB + SSW | N-1 | | |

**Decision**: Reject H₀ if F_calc > F_{α, k-1, N-k}

### 11. Chi-square Test of Independence
H₀: Attributes independent  
χ² = Σ(O - E)²/E where E = (Row Total × Col Total) / Grand Total  
df = (r-1)(c-1)  
Reject H₀ if χ²_calc > χ²_{α, df}

### 12. Simple Linear Regression
**Slope**: b = Σ(x-x̄)(y-ȳ) / Σ(x-x̄)² = [nΣxy - ΣxΣy] / [nΣx² - (Σx)²]  
**Intercept**: a = ȳ - b x̄  
**Correlation**: r = b × (σₓ/σᵧ) = [nΣxy - ΣxΣy] / √{[nΣx²-(Σx)²][nΣy²-(Σy)²]}  
**R²** = r² = Explained Variation / Total Variation

### 13. Control Charts (X-bar & R)
**X-bar Chart**: UCL = x̄̄ + A₂R̄, CL = x̄̄, LCL = x̄̄ - A₂R̄  
**R Chart**: UCL = D₄R̄, CL = R̄, LCL = D₃R̄  
Constants A₂, D₃, D₄ depend on sample size n

### 14. Stratified Sampling Allocation
**Proportional**: nᵢ = n × (Nᵢ/N)  
**Neyman (Optimum)**: nᵢ = n × (Nᵢσᵢ) / Σ(Nᵢσᵢ)  
**Equal**: nᵢ = n/k

### 15. Standard Error in SRS
**With Replacement**: SE = σ/√n  
**Without Replacement**: SE = (σ/√n) × √[(N-n)/(N-1)] (FPC)
**Sample Mean = Population Mean Proof**: E(x̄) = μ (show by taking expectation of sample mean)

## 📋 IMPORTANT LONG ANSWERS (10-Mark Style)

### 1. One-way ANOVA - Complete Procedure
**Scenario**: Compare k group means  
**Steps**: 
1. State H₀: μ₁ = μ₂ = ... = μₖ vs H₁: At least one differs
2. Calculate group means, grand mean
3. Compute SSB, SSW, SST
4. Construct ANOVA table
5. F_calc = MSB/MSW
6. Compare with F_{α, k-1, N-k}
7. Conclusion in context

**Pairwise Comparisons** (if H₀ rejected): Tukey's HSD, Bonferroni, Scheffé

### 2. Chi-square Test of Independence - Complete Procedure
**Given**: r × c contingency table  
**Steps**:
1. H₀: Row & column attributes independent
2. Expected Eᵢⱼ = (Rᵢ × Cⱼ) / N
3. χ² = Σ(Oᵢⱼ - Eᵢⱼ)²/Eᵢⱼ
4. df = (r-1)(c-1)
5. Compare with χ²_{α, df}
6. If 2×2 table: Use Yates' correction

### 3. Simple Linear Regression - Complete Analysis
**Given**: n pairs (xᵢ, yᵢ)  
**Steps**:
1. Scatter plot (visual check linearity)
2. Calculate b, a
3. Regression line: ŷ = a + bx
4. Calculate r, R²
5. Test H₀: β = 0 using t = b/SE(b) or F = MSR/MSE
6. Prediction: ŷ₀ = a + bx₀ with prediction interval
7. Residual analysis (check assumptions)

### 4. Time Series Decomposition & Forecasting
**Additive Model**: Yₜ = Tₜ + Sₜ + Cₜ + Iₜ  
**Multiplicative Model**: Yₜ = Tₜ × Sₜ × Cₜ × Iₜ  

**Methods**:
- **Moving Average**: Smooth trend, estimate seasonal indices
- **Least Squares**: Fit trend line (linear/quadratic)
- **Exponential Smoothing**: ŷₜ₊₁ = αyₜ + (1-α)ŷₜ
- **Seasonal Adjustment**: Deseasonalize → Forecast trend → Reseasonalize

### 5. Stratified Sampling - Complete Theory
**Estimation of Population Mean**: ȳ_st = Σ (Nᵢ/N) ȳᵢ  
**Variance**: V(ȳ_st) = Σ (Nᵢ/N)² (σᵢ²/nᵢ) (1 - nᵢ/Nᵢ)  
**Proportional Allocation**: nᵢ = n(Nᵢ/N) → V_prop = (1/n - 1/N) Σ Wᵢσᵢ²  
**Neyman Allocation**: nᵢ = n(Nᵢσᵢ)/Σ(Nᵢσᵢ) → V_opt = (1/n)[Σ Wᵢσᵢ]² - (1/N)Σ Wᵢσᵢ²  
**Efficiency Gain**: V_ran / V_opt = [Σ Wᵢσᵢ²] / [Σ Wᵢσᵢ]² ≥ 1

### 6. Hypothesis Testing Framework
**Steps**: (1) State H₀, H₁, (2) Choose α, (3) Select test statistic, (4) Determine critical region, (5) Compute statistic, (6) Decision, (7) Conclusion in words

**Key Tests**:
- **Z-test (Mean, σ known)**: Z = (x̄ - μ₀)/(σ/√n)
- **t-test (Mean, σ unknown)**: t = (x̄ - μ₀)/(s/√n)
- **Two-sample t-test (Equal variances)**: Pooled s²
- **Paired t-test**: On differences dᵢ
- **F-test (Variances)**: F = s₁²/s₂²
- **Chi-square (Variance)**: χ² = (n-1)s²/σ₀²
