## 📝 Question Type Distribution

### 2-Mark Questions (Very Short)
- All differentiation topics (see Important_Questions.md)
- Definitions: Class, Object, Encapsulation, Polymorphism, etc.
- Syntax: `super()`, `this()`, `final`, `static`, `throw/throws`
- Constants: Thread priorities, Isolation levels, Driver types

### 5-Mark Questions (Short Answer)
- Theory + Code: Encapsulation, Constructors, `super`, `final`, `static`
- Thread Creation (Thread class + Runnable)
- Exception Handling: try-catch-finally, throw/throws, Custom Exception
- JDBC: Driver Types, Connection Steps, PreparedStatement
- String/StringBuilder programs
- JavaFX: Event Handling, Layouts, CSS

### 10-Mark Questions (Long Answer)
- **Inheritance**: Types, advantages, `super`, constructor chaining
- **Polymorphism**: Static vs Dynamic, Overloading vs Overriding, Abstract vs Interface
- **Exception Handling**: Hierarchy, checked/unchecked, custom exceptions
- **Multithreading**: Creation, Life Cycle (diagram), Synchronization, wait/notify
- **JDBC**: Architecture (2/3 tier diagrams), Driver Types, Transactions
- **Streams**: Byte vs Character, Serialization
- **GUI**: AWT vs Swing vs JavaFX, JavaFX components/layouts/events
